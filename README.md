<b>Live URL = https://webchat-imessager-8sh9.onrender.com

Webchat Instant Messaging App using MERN Stack, Socket.io, Clerk, Render, Webhooks, Cronjobs, ImageKit.io.
Engineered a high-concurrency real-time instant messaging application utilizing Node.js WebSocket servers and Clerk OAuth
authentication. Integrated media storage pipeline using ImageKit.io supporting high-speed image, audio, and video media file sharing.
Implemented custom application themes, dark/light mode toggles, custom chat wallpapers, and background Cronjobs
cleanups.</b>


<b>Features in this project 🔥</b>
<br>
✅ Full Stack Real-Time Chat App built from scratch <br>
✅ Frontend with React, Tailwind CSS & Hero UI <br>
✅ Backend with Node.js & Express.js <br>
✅ Authentication with Clerk <br>
✅ MongoDB Database Integration <br>
✅ Real-Time Messaging with Socket.io <br>
✅ Online User Presence Tracking <br>
✅ Image & Video Sharing Support <br>
✅ Dark/Light Mode + Multiple Themes & Wallpapers <br>
✅ Optional Keyboard Sound Effects <br>
✅ Build Your Own WebSocket Server (No Firebase/Supabase) <br>
✅ Media Uploads & Transformations with ImageKit <br>
✅ Webhooks, Cron Jobs & Middleware Explained <br>
✅ File Uploads from Scratch <br>
✅ Deployment - Render application <br>
